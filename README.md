# Ironside Heating, Cooling & Plumbing — Standard Package (Concept)

Multi-page website for an HVAC and plumbing company in Columbus, OH.

**Pages:** Home · Services (category filter + maintenance plan comparison) · Service detail (dynamic, 8 services with pricing, signs, what's included, process, FAQ) · About (story, values, team, timeline) · Service Areas (ZIP checker, 16 communities, map) · Reviews & FAQ (rating breakdown, filter by service, accordion) · Book Service (multi-step request form with urgency, date and arrival window).

**Highlights:** 24/7 emergency banner, shared header/footer components, data-driven service and review cards, click-to-call floating button on mobile, SEO meta tags, responsive layout.

**Tech:** HTML5, CSS3, vanilla JavaScript. Photos: Unsplash.

*Concept / demo project — Ironside is a fictional brand. Forms send nothing.*
